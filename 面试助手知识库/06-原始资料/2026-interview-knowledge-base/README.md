# 26年面试知识库

面向 2026 年 AI 开发与嵌入式 Linux 岗位准备的个人统一面试知识库。

## 内容

- `interview_kb.jsonl`：当前面试助手实际使用的统一知识库，共 440 条记录。
- 每行一个 UTF-8 JSON 对象，包含标题、回答内容、关键词、岗位方向、项目归属、证据状态和来源说明等字段。
- 覆盖 AI Agent、嵌入式 Linux、六个个人项目、基础知识、行为面试及压力追问。

## 学习资料

- `学习资料/AI应用系统工程师/00_阅读索引.md`：AI 应用系统工程师方向的学习入口。

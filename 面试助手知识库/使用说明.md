# 使用说明

## 文件位置
本目录位于项目根目录下的 `面试助手知识库/`，可在 GitHub 浏览，也可下载后用 Obsidian 打开为笔记库。
这里的 Markdown 文件就是笔记，编辑后由 Obsidian 自动保存。Finder 和 Obsidian 看到的是同一份文件。

## 日常操作
1. 从 [项目经历索引](01-项目经历/项目经历索引.md)、[私人知识库总览](04-面试问答/私人知识库总览.md) 或 [整理与学习方案](知识库整理审查与学习方案.md) 开始阅读。
2. 先看题目，尝试口述，再点击“参考答案”或“源库答案”展开核对。
3. 写下自己的说法，补充真实项目实例和不确定之处。
4. 新增笔记可在目标文件夹上右键创建。复制模板时为副本改一个明确标题。
5. 在笔记中输入双中括号并选择另一篇笔记，即可建立内部链接。

## 放入已有资料
- Markdown：把文件复制到对应主题文件夹；附带图片也一起复制并检查链接。
- PDF、图片：可以拖到打开的笔记中，附件会存入“附件”文件夹。
- JSONL：应转换为按主题组织的 Markdown；不要直接改扩展名。
- 已从指定私有仓库导入 440 条知识和 3 份学习资料，入口见 [[04-面试问答/私人知识库总览]]。原始 JSONL 保留为快照，源仓库位于 `/Users/hanzhongyi/Developer/WORKSPACE/2026-interview-knowledge-base`。

## 与面试助手的关系
这里用于人工阅读、记忆和整理。面试助手读取 [knowledge_source/interview_kb.jsonl](../knowledge_source/interview_kb.jsonl)，运行时路径优先级见 [配置说明](../knowledge_source/README.md)。
当前没有建立自动同步或导出流程；在这里改笔记不会自动更新面试助手。

GitHub 中保留知识笔记、来源快照、复习模板和练习代码；本机 Obsidian 状态、生成缓存、空白草稿和日期命名的真实问答测试报告不上传。

## 复习方法
每天选 5～10 个问题。先回忆，再对照；优先复习上次答不好的内容。
可先安排当天、次日、三天后和一周后的复习，再按熟练程度调整。
这是手动复习安排，尚未配置通知或自动提醒。

## 备份
定期复制整个“面试知识库”文件夹到另一块磁盘，建议使用带日期的目录。
备份时保留隐藏的 `.obsidian` 文件夹以保存设置。备份后抽查一篇笔记和一个附件能否打开。
本次未新增 Obsidian Sync、定时备份或第三方插件。Finder 将“文稿”显示在 iCloud 云盘路径下；本仓库会遵循你原有的系统同步设置，本次没有修改该设置。

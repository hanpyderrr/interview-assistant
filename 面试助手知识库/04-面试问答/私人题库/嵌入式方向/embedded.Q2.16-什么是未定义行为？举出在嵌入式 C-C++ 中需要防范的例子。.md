# 什么是未定义行为？举出在嵌入式 C/C++ 中需要防范的例子。

> [!warning] 阅读边界
> 证据：草稿待核对（draft）；审核：待CC审核（cc_pending）。状态沿用源库，本次导入未重新核验事实。 请先核对项目事实与指标，再用于面试口述。

> [!note]- 源库答案（原文）
> 未定义行为是标准不对程序结果作任何要求的行为，编译器可假定它不会发生并据此优化，所以不只是偶尔崩溃。常见例子：越界访问、使用已释放对象、解引用空或错误对齐指针、有符号整数溢出、数据竞争、错误格式化参数、对象生命周期外访问、违反严格别名。嵌入式边界：直接读取协议字节时的非对齐强转、ISR 与线程无同步共享变量、移位位数不合法、DMA 仍在使用时复用缓冲区都值得重点防范。硬件寄存器访问通常依赖实现扩展和平台头文件，应按编译器/芯片 ABI 使用。排查：打开高等级警告、ASan/UBSan、静态分析和边界测试；对协议长度先验证再计算目标偏移。

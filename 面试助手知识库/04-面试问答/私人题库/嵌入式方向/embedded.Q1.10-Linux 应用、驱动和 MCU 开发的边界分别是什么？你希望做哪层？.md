# Linux 应用、驱动和 MCU 开发的边界分别是什么？你希望做哪层？

> [!warning] 阅读边界
> 证据：草稿待核对（draft）；审核：待CC审核（cc_pending）。状态沿用源库，本次导入未重新核验事实。 请先核对项目事实与指标，再用于面试口述。

先尝试口述，再展开源库答案。

> [!note]- 源库答案（原文）
> Linux 应用运行在用户态，通过系统调用和设备节点使用内核能力，关注业务、并发、网络和数据处理；Linux 驱动运行在内核态，管理硬件资源、中断、DMA、电源和内核子系统，对稳定性与并发约束更严格；MCU 开发通常直接操作寄存器/HAL/RTOS，资源有限、实时性更强，软硬件边界更近。个人定位：当前希望重点做 AI 应用系统的 Python 后端、推理/RAG 链路和全栈落地，同时保留 Linux 系统与设备侧经验作为差异化能力。应明确自己封装过设备节点接口并参与联调，不等于独立开发过 Linux 内核驱动。

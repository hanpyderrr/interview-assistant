# PWM 的频率和占空比分别影响什么？

> [!warning] 阅读边界
> 证据：草稿待核对（draft）；审核：待CC审核（cc_pending）。状态沿用源库，本次导入未重新核验事实。 请先核对项目事实与指标，再用于面试口述。

先尝试口述，再展开源库答案。

> [!note]- 源库答案（原文）
> 对 STEP/DIR 步进驱动器，脉冲频率主要决定步进速度，脉冲个数决定位移；占空比通常只需满足驱动器最小高/低电平时间，并不直接决定力矩。对直流电机电压型 PWM，占空比影响平均电压/转矩，频率影响电流纹波、噪声和开关损耗。必须先说明驱动接口类型。步进电机相电流和力矩多由驱动器电流环/细分配置决定；频率过高或加速度过大可能失步。PWM 参数还受定时器时钟、计数分辨率和驱动器 datasheet 限制。项目结合：本项目电机是 TMC2209 STEP/DIR 步进驱动器——调速靠脉冲频率、定位靠脉冲数，占空比只需满足驱动器最小高低电平时间；不主动展开 PWM 的具体用途，被问到时按上面两类 PWM 的区别回答，不编造本项目 PWM 的用途。

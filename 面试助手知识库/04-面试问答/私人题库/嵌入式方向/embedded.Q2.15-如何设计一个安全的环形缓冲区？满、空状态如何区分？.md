# 如何设计一个安全的环形缓冲区？满、空状态如何区分？

> [!warning] 阅读边界
> 证据：草稿待核对（draft）；审核：待CC审核（cc_pending）。状态沿用源库，本次导入未重新核验事实。 请先核对项目事实与指标，再用于面试口述。

先尝试口述，再展开源库答案。

> [!note]- 源库答案（原文）
> 环形缓冲区至少需要固定容量、读索引和写索引。可保留一个槽位：read == write 表示空，(write + 1) % capacity == read 表示满；也可额外维护元素计数或单独的 full 标志，从而使用全部槽位。写入前检查可用空间，读取前检查已有数据；批量读写要正确处理绕回，并避免 size + incoming 的整数溢出。并发版本必须定义生产者/消费者模型：SPSC 可用原子索引和正确内存序，MPSC/MPMC 复杂得多，通常优先使用锁或成熟队列；还要明确满时阻塞、丢新数据、覆盖最旧数据还是背压。项目结合：图像链路可在槽元数据中加入长度、序号、时间戳和状态；慢显示与关键采集对丢旧帧/不丢帧的策略往往不同。

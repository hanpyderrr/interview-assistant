# 整个 Agent 是怎么运转的？从用户输入到最终完成任务，中间经历了哪些步骤？

> [!warning] 阅读边界
> 证据：草稿待核对（draft）；审核：待CC审核（cc_pending）。状态沿用源库，本次导入未重新核验事实。 请先核对项目事实与指标，再用于面试口述。

先尝试口述，再展开源库答案。

> [!note]- 源库答案（原文）
> Agent 的核心不是一次模型调用，而是一个受控闭环。用户输入先经过身份、权限和安全校验，再被解析成目标、约束与完成标准；规划器据此拆解步骤，运行时为每一步选择模型、知识检索或工具。执行后要校验工具结果并更新显式状态，失败则按策略重试、改路或请求人工介入。最后依据完成标准汇总证据、生成答复，同时记录轨迹、成本和审计信息。关键是把模型的概率性决策限制在确定性的权限、状态机和预算边界内。

# Agent 如何支持暂停、恢复、重试、回滚、人工干预和任务回放？

> [!warning] 阅读边界
> 证据：草稿待核对（draft）；审核：待CC审核（cc_pending）。状态沿用源库，本次导入未重新核验事实。 请先核对项目事实与指标，再用于面试口述。

先尝试口述，再展开源库答案。

> [!note]- 源库答案（原文）
> 如果由我设计，会把 Agent 执行建成持久化状态机，每个节点完成后写 checkpoint 和追加式事件。暂停只在安全点生效，冻结可调度节点；恢复时加载最近 checkpoint，核对模型、工具、权限和输入版本后继续。重试按错误类型决定，瞬时错误退避重试，业务错误不盲重试，并用幂等键防止副作用重复。回滚不能假设数据库事务能覆盖外部系统，应为已提交动作定义补偿步骤。人工干预通过待审批状态修改参数、跳过或终止，所有操作留审计。回放区分只读模拟和真实重放，默认屏蔽外部副作用，并固定版本与随机性信息。

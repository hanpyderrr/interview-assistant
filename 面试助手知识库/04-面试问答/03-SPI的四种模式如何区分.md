# SPI的四种模式如何区分

先口述，再展开答案。下面是通用参考，不代表个人项目经历。

> [!note]- 参考答案（点击展开）
> SPI 模式由 CPOL 和 CPHA 两位组合：模式 0 是 0/0，模式 1 是 0/1，模式 2 是 1/0，模式 3 是 1/1。CPOL 描述时钟空闲电平；CPHA 描述在第一个还是第二个时钟边沿采样。必须依据设备数据手册选择。

## 原理与细节
第一个边沿是离开空闲电平的边沿，不总是上升沿。
